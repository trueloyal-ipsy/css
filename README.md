# IPSY custom CSS scripts

The custom CSS running on IPSY's four live TrueLoyal stores (US and MX, prod and staging). Each environment has its own folder with one `custom.css`. When the CSS changes, the file is overwritten, so the git history shows what changed and when.

## Layout

```text
MX-prod/custom.css
MX-staging/custom.css
US-prod/custom.css
US-staging/custom.css
```
